## What was built

**LUMENFALL — Neon Survivor**, an original top-down 2D arena survival game
(Vampire-Survivors-like). Vanilla ES modules on one `<canvas>`; all art and
sound generated in code; zero libraries, zero assets, zero network requests.

- 10 waves in a neon arena; XP shards, level-ups with 1-of-3 cards (5 weapons
  to level 5, 6 stat boosts); elites from wave 3; boss wave 5 (the Warden)
  and wave 10 (the Hollow Star, the win condition); combo multiplier; dash
  with i-frames; particles, screen shake, hit-stop, floating damage numbers,
  knockback; WebAudio synth SFX + generative music loop (mutable).
- Screens: title with live attract mode, how-to-play, pause, level-up,
  boss banners, victory, game over (with run stats + restart). HUD: HP, XP
  bar + level, wave + timer, score, combo, dash cooldown, boss HP bar,
  off-screen boss indicator, arsenal list. Best score/wave in localStorage.
- Fixed 60 Hz timestep, object pools, seeded RNG (`?seed=N`), hidden
  `?debug=1` (boosted run at wave 9, for testing the boss/win path),
  `?fps=1` counter, `?shot=start|play|levelup|end` deterministic screenshot
  staging.

## Bugs found and fixed during testing

1. **Shot mode painted black frames.** `runShot` painted twice and stopped;
   a resize event fired after the paints cleared the canvas and nothing
   repainted. Fixed: shot mode now repaints every frame until the page is
   closed (`game/src/main.js`, `runShot`).
2. **Title footer overlapped the HOW TO PLAY button.** The `v1.0 — …` line
   sat inside the button's rect. Fixed: footer moved below the panel
   (`render.js`, `drawTitle`).
3. **Mute button overlapped the SCORE text** (top-right corner). Fixed:
   mute button moved to the bottom-right, clear of the dash indicator
   (`ui.js`, `titleLayout`).
4. **"Damage dealt" stat was hidden behind the RUN IT BACK button** on the
   game-over screen (7th stat line vs button at y=440). Fixed: game-over
   and victory panels enlarged, buttons moved down (`ui.js`,
   `overLayout`/`winLayout`); the pause panel got the same treatment
   (last button overflowed 4 px).
5. **Space didn't dash.** `input.js` mapped Space to confirm only, while
   the HUD promises "DASH READY [SPACE]" and the brief says Space = dash.
   Fixed: Space now sets dash + confirm; the loop only confirms on menu
   screens and only dashes in play, so one key doing both is unambiguous.
   Shift still dashes too.
6. **Play screenshot was empty.** Staging 34 s landed in the wave-1 lull
   (field cleared, 8 s left). Fixed: play shot now stages 100 s in
   (wave 3, ~12 s in, mixed enemy kinds).
7. **Test-harness fixes (not game bugs):** this VM's browser blocks
   `http://127.0.0.1` navigations from CDP (Local Network Access checks —
   flags, managed policy and `Browser.setPermission` all failed to lift
   it), so the harnesses run the game from `tests/bundle.html` via
   `file://` (same code, import/export lines stripped, verified identical
   behaviour). Puppeteer was abandoned (same LNA block + its `--screenshot`
   wrote nothing). The CDP driver opens each page in a fresh tab and drops
   the device-metrics override, which had been firing a resize that cleared
   painted canvases. The headless viewport is 1280×639, not 1280×720, so
   the playtest clicks by logical coordinates, converting through the live
   canvas geometry.

## Known issues / tuning notes

- **Difficulty:** a decent autopilot reaches wave 5 and dies there; a dumb
  one (first card, never dashes) dies on wave 3. The Warden is killable
  with a mid-game loadout and the Hollow Star dies with a good build, so
  the win is reachable — but wave 5 is a genuine wall for a mediocre
  player. A human who kites the boss and picks weapons deliberately should
  do better than either bot. If the parent wants it softer, the cheapest
  knobs are `ENEMY.brute.damage` / `wavePlan` counts in `config.js`.
- The level-up screen's HUD can sit under an enemy glow at the field edge;
  the text stays on top and readable — cosmetic only.
- `?debug=1` writes `bestWave: 9` when the debug boss is killed (the wave
  counter is still 9 at that moment); real games record wave 10 correctly.
